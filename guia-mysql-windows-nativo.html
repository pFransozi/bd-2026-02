MySQL no Windows com instalação nativa

Instale o MySQL 8.4 LTS como serviço do Windows, prepare a conta de laboratório e execute o primeiro teste SQL no DBeaver.

Para preparar o servidor em um contêiner, siga o outro roteiro. Guia com Docker Desktop →

Como as ferramentas se conectam

O MySQL Community Server roda como serviço do Windows e mantém os dados em disco. O DBeaver é o cliente gráfico que se conecta ao serviço para executar SQL e consultar tabelas.

Você vai usar a conta root para preparar o banco e a conta aluno para executar o roteiro.

1. Confira os requisitos e a porta

  1. Use Windows 11 de 64 bits em um PC Intel ou AMD. Para instalar o servidor como serviço, tenha acesso de administrador. Plataformas suportadas pelo MySQL.
  2. Se o computador já tem MySQL 8.4 funcionando, use a instalação existente e avance para a verificação do serviço.
  3. No PowerShell, confira se um processo já está escutando na porta padrão do MySQL.
PowerShell · consultar a porta 3306
Get-NetTCPConnection -LocalPort 3306 -State Listen -ErrorAction SilentlyContinue

Uma saída com registros indica que a porta está em uso. Se for instalar outra instância, escolha uma porta livre, como 3308, e anote-a para usar no DBeaver e na prática.

2. Baixe o MySQL Community Server

  1. Confira se o Windows tem o Microsoft Visual C++ Redistributable v14 (x64). Instale o pacote se necessário. Download do Visual C++ Redistributable.
  2. Na série 8.4 LTS, selecione Microsoft Windows e baixe Windows (x86, 64-bit), MSI Installer. Download oficial do MySQL Community Server.
  3. Se aparecer a tela de cadastro, escolha No thanks, just start my download.

O MSI inclui o MySQL Configurator, usado na próxima etapa. O instalador do DBeaver fica disponível separadamente na etapa de configuração da conexão.

3. Instale e configure o servidor

Execute o arquivo .msi, aceite a licença e escolha a instalação típica. Ao final, abra o MySQL Configurator pelo instalador ou pelo menu Iniciar.

TelaComo preencher
Data DirectoryMantenha o diretório de dados sugerido para uma instalação nova.
Type and NetworkingEscolha Development (ou Development Computer), mantenha TCP/IP e use 3306 ou a porta livre escolhida. Se o configurador apontar conflito em X Protocol Port, escolha outra porta livre para esse campo. Para a conexão local, desmarque Open Windows Firewall port for network access.
Accounts and RolesDefina e confirme uma senha própria para a conta administrativa root.
Windows ServiceMantenha o servidor como serviço, com início automático. Anote o nome exibido, normalmente MySQL84.
Apply ConfigurationAvance com os valores sugeridos nas telas restantes. Clique em Execute, aguarde a confirmação das etapas e conclua o configurador.

A senha de root será usada para criar o banco e a conta do laboratório. Telas do MySQL Configurator.

4. Confirme o serviço do Windows

  1. Pressione Win + R, digite services.msc e pressione Enter.
  2. Procure MySQL84 ou o nome anotado no configurador. Confira se o estado está Em execução. Se necessário, use Iniciar com uma conta autorizada no Windows.
  3. No PowerShell, teste a porta escolhida. Substitua 3306 se configurou outra porta.
PowerShell · testar a porta do MySQL
Test-NetConnection -ComputerName 127.0.0.1 -Port 3306

TcpTestSucceeded deve mostrar True. O teste SQL no DBeaver vai confirmar o banco e a conta utilizados.

5. Prepare o banco e a conta de laboratório

Abra a conexão administrativa

Se já usa o DBeaver Community nas aulas, abra a instalação existente. Para instalar no Windows em um PC Intel ou AMD, baixe o EXE na opção Windows · x86 e siga o assistente. Download do DBeaver Community.

No DBeaver, pressione Ctrl + Shift + N, pesquise MySQL, selecione esse driver e avance.

Preencha o host com 127.0.0.1, a porta com a escolhida no configurador, o usuário com root e a senha com a da conta administrativa. Deixe o campo Database em branco nesta conexão.

Use TLS no DBeaver

Na aba Driver properties, localize sslMode e altere seu valor para REQUIRED. Essa opção faz o driver exigir uma conexão criptografada com o MySQL.

Clique em Test Connection (Testar conexão). Se aparecer uma solicitação para instalar o driver, clique em Download. Após a confirmação, clique em Finish (Concluir).

Crie o banco e conceda acesso

Abra um editor SQL na conexão de root. Substitua o valor troque-a-senha-aluno por uma senha própria para o laboratório. Execute o bloco com Alt + X.

SQL como root · preparar o laboratório
CREATE DATABASE IF NOT EXISTS laboratorio
    CHARACTER SET utf8mb4;

CREATE USER IF NOT EXISTS 'aluno'@'127.0.0.1'
    IDENTIFIED BY 'troque-a-senha-aluno';

GRANT ALL PRIVILEGES ON laboratorio.* TO 'aluno'@'127.0.0.1';

O utf8mb4 armazena nomes com acentos. A conta de laboratório aceita conexões pelo endereço 127.0.0.1 e pode criar, modificar e consultar os objetos de laboratorio.

Se a conta já existe

Use a senha previamente cadastrada para 'aluno'@'127.0.0.1'. O comando CREATE USER IF NOT EXISTS permite continuar a configuração do banco quando a conta já está criada.

6. Registre a conexão de aluno no DBeaver

Abra uma nova conexão MySQL com Ctrl + Shift + N e preencha os campos.

CampoValorO que indica
Host127.0.0.1O próprio computador.
Port (Porta)3306 ou a porta escolhidaPorta em que o serviço do Windows está escutando.
Database (Banco de dados)laboratorioBanco selecionado ao abrir a conexão.
Username (Usuário)alunoConta utilizada para executar os comandos.
Password (Senha)Senha definida no CREATE USERSenha da conta MySQL.

Abra Driver properties neste perfil de aluno e defina sslMode como REQUIRED.

Clique em Test Connection (Testar conexão). Se aparecer uma solicitação para instalar o driver, clique em Download. Após a confirmação, clique em Finish (Concluir).

Você pode nomear a conexão MySQL · Laboratório (nativo). Use essa conexão para o teste SQL e para trabalhar com os dados do laboratório.

Depois de conectar, abra um editor SQL nessa conexão para conferir o TLS.

SQL · conferir a criptografia da sessão
SHOW SESSION STATUS LIKE 'Ssl_cipher';

Um valor preenchido na coluna Value confirma que a sessão usa TLS.

7. Crie uma tabela e execute consultas

Selecione a conexão de aluno no DBeaver e abra SQL Editor → New SQL Editor. Posicione o cursor no comando e pressione Ctrl + Enter para executá-lo. Comece pela conferência da conexão.

SQL · conferir a conexão
SELECT DATABASE() AS banco,
       CURRENT_USER() AS usuario,
       @@port AS porta_servidor,
       VERSION() AS versao;

Confira laboratorio, aluno@127.0.0.1, a porta escolhida e a versão 8.4.x. Se aparecer root@localhost, abra o editor a partir da conexão de aluno.

Crie a tabela de centros de distribuição

A chave primária identifica cada centro. O MySQL gera o id_centro com AUTO_INCREMENT e verifica a capacidade com CHECK.

SQL · criar a tabela
CREATE TABLE centro_distribuicao (
    id_centro INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(80) NOT NULL,
    cidade VARCHAR(80) NOT NULL,
    capacidade_diaria INT NOT NULL CHECK (capacidade_diaria > 0)
) ENGINE=InnoDB;

Insira quatro registros

SQL · cadastrar os centros
INSERT INTO centro_distribuicao (nome, cidade, capacidade_diaria)
VALUES
    ('CD Curitiba Norte', 'Curitiba', 600),
    ('CD Curitiba Sul', 'Curitiba', 800),
    ('CD São José', 'São José dos Pinhais', 650),
    ('CD Londrina', 'Londrina', 500);

Se o DBeaver estiver no modo de confirmação manual, clique em Commit após a inserção.

Consulte os registros

SQL · listar os centros
SELECT id_centro, nome, cidade, capacidade_diaria
FROM centro_distribuicao
ORDER BY id_centro;
Resultado esperado

A consulta retorna quatro linhas. Para ver a tabela na árvore do DBeaver, atualize a pasta Tables do banco laboratorio.

Retome a agregação da Aula 09

O GROUP BY reúne os centros por cidade. Para cada grupo, COUNT(*) conta os centros e SUM soma suas capacidades. Revisar a Aula 09.

SQL · agrupar os centros por cidade
SELECT cidade,
       COUNT(*) AS total_centros,
       SUM(capacidade_diaria) AS capacidade_total
FROM centro_distribuicao
GROUP BY cidade
ORDER BY capacidade_total DESC;

Em um banco laboratorio recém-preparado, você também pode colar o script completo no editor e pressionar Alt + X para executá-lo. Faça a criação e a inserção uma vez. Nas próximas execuções, selecione apenas as consultas. Baixar o script de teste (.sql).

8. Inicie o serviço e confira os dados

No painel Serviços do Windows, use Iniciar, Parar ou Reiniciar conforme necessário. O início automático faz o MySQL iniciar com o sistema.

Para conferir a persistência, reinicie o serviço, reconecte no DBeaver e execute a consulta abaixo. O resultado esperado é 4.

SQL · contar os centros após reiniciar
SELECT COUNT(*) AS total
FROM centro_distribuicao;

Para gerar uma cópia lógica do banco, o MySQL inclui o utilitário mysqldump. Manual do mysqldump.

9. Diagnostique problemas comuns

ProblemaO que conferir
O instalador pede administradorUse uma conta autorizada a instalar o servidor e a configurar serviços no Windows.
Porta 3306 ocupadaConfira o processo que a utiliza. Para uma instalação separada, escolha uma porta livre no configurador e repita-a no DBeaver.
Connection refusedConfira o estado do serviço em services.msc e teste o host e a porta.
Public Key Retrieval is not allowedConfigure sslMode=REQUIRED em Driver properties da conexão e repita o teste.
Access denied para rootRedigite a senha definida em Accounts and Roles e confira a instância selecionada e o sslMode no perfil de root.
Access denied para alunoConfira o host 127.0.0.1, a porta e a senha cadastrada para essa conta.
Banco laboratorio indisponívelConfira na conexão de root se o banco foi criado e se o GRANT foi executado na mesma instância.
Tabela já existenteConsulte a tabela. Se estiver vazia, execute só a inserção. Se já tiver os quatro registros, execute apenas as consultas.

Prática da Aula 10 e referências

A prática de reservas usa um banco próprio, pratica_salas. Você pode executar no DBeaver os mesmos comandos SQL do roteiro e usar duas conexões separadas para o teste de concorrência.

Preparar o banco e o acesso de aluno

No DBeaver, abra o editor SQL da conexão administrativa de root e execute o bloco.

SQL · criar o banco da prática e conceder acesso
CREATE DATABASE IF NOT EXISTS pratica_salas CHARACTER SET utf8mb4;
GRANT ALL PRIVILEGES ON `pratica\_salas`.* TO 'aluno'@'127.0.0.1';

Depois, abra a conexão de aluno para pratica_salas. No arquivo .env da aplicação, use MYSQL_DATABASE=pratica_salas, MYSQL_USER=aluno, a senha dessa conta e MYSQL_PORT=3306 se você usou a porta deste guia.
