# Banco de Dados — materiais 2026/2

Estrutura:

- `index.html`: página principal.
- `curso.html`: apresentação da disciplina, percurso, ferramentas, calendário, avaliações, APS, projeto e protocolo IA-First.
- `aula-02.html`: primeiro encontro efetivo — apresentação do curso e fundamentos de banco de dados.
- `atividade-arquivos-sgbd.md`: atividade complementar da Aula 02.
- `styles.css`: estilos compartilhados, responsivos e com modo noturno.
- `script.js`: navegação móvel, modo noturno e ampliação dos infográficos.
- `assets/percurso-banco-dados.svg`: mapa do semestre.
- `assets/ecossistema-ferramentas.svg`: mapa das ferramentas.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.
