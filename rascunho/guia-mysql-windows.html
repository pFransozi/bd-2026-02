MySQL no Windows com Docker Desktop

Prepare o MySQL 8.4 LTS em um contêiner, conecte o DBeaver ao banco de laboratório e execute o primeiro teste SQL.

Para configurar o MySQL como serviço do Windows, use o outro roteiro. Guia de instalação nativa →

Ambiente WSL 2 Docker Desktop Servidor DBeaver Primeiro SQL Uso diário Problemas Prática e fontes

Como as ferramentas se conectam

O Docker Desktop executa o servidor MySQL em um contêiner Linux. O DBeaver, instalado no Windows, é o cliente que envia comandos SQL. O MySQL grava os arquivos do banco no volume mysql_dados.

DBeaverWindows · 127.0.0.1:3307
→
MySQL 8.4 LTSContêiner Linux · porta 3306
→
Volume mysql_dadosArquivos persistentes do servidor

Execute os comandos de configuração no PowerShell e use o editor do DBeaver para os comandos SQL.

1. Verifique o Windows e o WSL 2

Para este roteiro, use Windows 11 de 64 bits com virtualização habilitada. Confira os requisitos oficiais para a sua versão do Windows e do WSL. Requisitos do Docker Desktop.

Abra o PowerShell e verifique a versão instalada do WSL.

PowerShell · verificar o WSL
wsl --version

Se precisar instalar o WSL, abra o PowerShell como administrador e execute o comando abaixo. Reinicie se o Windows solicitar.

PowerShell como administrador · instalar o WSL
wsl --install --no-distribution

Para atualizar uma instalação existente, execute wsl --update. Comandos do WSL.

2. Instale e abra o Docker Desktop

  1. Baixe o instalador para o seu Windows. Download do Docker Desktop.
  2. Use o backend WSL 2 e abra o Docker Desktop. Aguarde a inicialização do mecanismo.
  3. No PowerShell, confira o Compose e o tipo de contêiner.
PowerShell · verificar o Docker
docker compose version
docker info --format '{{.OSType}}'

O segundo comando deve retornar linux. Se a conexão com o mecanismo falhar, confira se o Docker Desktop terminou de iniciar.

3. Inicie o MySQL com Docker Compose

Prepare a pasta e o arquivo

O arquivo compose.yaml define a imagem, as contas, a porta e o volume. Crie uma pasta para ele e abra o arquivo no Bloco de Notas. Você também pode baixar o arquivo e salvá-lo nessa pasta. Baixar compose.yaml.

PowerShell · criar a pasta do laboratório
$pasta = Join-Path $env:USERPROFILE "mysql-laboratorio"
New-Item -ItemType Directory -Force -Path $pasta
Set-Location $pasta
notepad compose.yaml

Salve o conteúdo com o nome compose.yaml. Substitua troque-a-senha-root e troque-a-senha-aluno por duas senhas próprias. Para representar um $ em um valor no Compose, escreva $$.

compose.yaml · MySQL 8.4 LTS
services:
  mysql:
    image: mysql:8.4
    restart: unless-stopped
    environment:
      MYSQL_ROOT_HOST: "localhost"
      MYSQL_ROOT_PASSWORD: "troque-a-senha-root"
      MYSQL_DATABASE: "laboratorio"
      MYSQL_USER: "aluno"
      MYSQL_PASSWORD: "troque-a-senha-aluno"
    ports:
      - "127.0.0.1:3307:3306"
    volumes:
      - mysql_dados:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "127.0.0.1", "--silent"]
      interval: 5s
      timeout: 5s
      start_period: 30s
      retries: 12

volumes:
  mysql_dados:
Porta do Windows e porta do contêiner

O DBeaver usa 127.0.0.1:3307. O Docker encaminha essa conexão para a porta 3306 do MySQL no contêiner. A porta externa 3307 permite usar o guia junto de uma instalação nativa na 3306.

Na primeira inicialização de um volume vazio, a imagem cria laboratorio e dá à conta aluno acesso a esse banco. A conta administrativa root é usada pelo terminal do contêiner neste roteiro.

Inicie e confira o serviço

No PowerShell, na pasta que contém o arquivo, execute os três comandos.

PowerShell · validar, iniciar e conferir
docker compose config --quiet
docker compose up -d --wait
docker compose ps

Na primeira execução, o Docker baixa a imagem e inicializa os dados. Confira se o serviço mysql aparece como healthy. Esse estado indica que o servidor responde. A autenticação será conferida no DBeaver.

Ver os logs e testar a conexão pelo terminal
PowerShell · diagnóstico do MySQL
docker compose logs --tail=30 mysql
docker compose exec mysql mysql -h 127.0.0.1 -u aluno -p -D laboratorio -e "SELECT DATABASE() AS banco, CURRENT_USER() AS usuario;"

Digite a senha de MYSQL_PASSWORD quando solicitada. Confira se o banco é laboratorio e a conta autenticada começa com aluno@.

4. Configure a conexão no DBeaver

Se já usa o DBeaver Community nas aulas, abra a instalação existente. Para instalar no Windows em um PC Intel ou AMD, baixe o EXE na opção Windows · x86 e siga o assistente. Download do DBeaver Community.

No DBeaver, pressione Ctrl + Shift + N, pesquise MySQL, selecione esse driver e avance.

CampoValorO que indica
Host127.0.0.1O próprio computador.
Port (Porta)3307Porta publicada pelo Docker no Windows.
Database (Banco de dados)laboratorioBanco selecionado ao abrir a conexão.
Username (Usuário)alunoConta utilizada para executar os comandos.
Password (Senha)Valor de MYSQL_PASSWORDSenha da conta MySQL.

Clique em Test Connection (Testar conexão). Se aparecer uma solicitação para instalar o driver, clique em Download. Após a confirmação, clique em Finish (Concluir).

Você pode nomear a conexão MySQL · Laboratório (Docker) para reconhecê-la no navegador de bancos.

5. Crie uma tabela e execute consultas

Selecione a conexão de aluno no DBeaver e abra SQL Editor → New SQL Editor. Posicione o cursor no comando e pressione Ctrl + Enter para executá-lo. Comece pela conferência da conexão.

SQL · conferir a conexão
SELECT DATABASE() AS banco,
       CURRENT_USER() AS usuario,
       @@port AS porta_servidor,
       VERSION() AS versao;

Confira laboratorio, a conta aluno@% e a versão 8.4.x. A coluna porta_servidor mostra 3306, a porta interna. O DBeaver acessa o contêiner pela porta publicada 3307.

Crie a tabela de centros de distribuição

A chave primária identifica cada centro. O MySQL gera o id_centro com AUTO_INCREMENT e verifica a capacidade com CHECK.

SQL · criar a tabela
CREATE TABLE centro_distribuicao (
    id_centro INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(80) NOT NULL,
    cidade VARCHAR(80) NOT NULL,
    capacidade_diaria INT NOT NULL CHECK (capacidade_diaria > 0)
) ENGINE=InnoDB;

Insira quatro registros

SQL · cadastrar os centros
INSERT INTO centro_distribuicao (nome, cidade, capacidade_diaria)
VALUES
    ('CD Curitiba Norte', 'Curitiba', 600),
    ('CD Curitiba Sul', 'Curitiba', 800),
    ('CD São José', 'São José dos Pinhais', 650),
    ('CD Londrina', 'Londrina', 500);

Se o DBeaver estiver no modo de confirmação manual, clique em Commit após a inserção.

Consulte os registros

SQL · listar os centros
SELECT id_centro, nome, cidade, capacidade_diaria
FROM centro_distribuicao
ORDER BY id_centro;
Resultado esperado

A consulta retorna quatro linhas. Para ver a tabela na árvore do DBeaver, atualize a pasta Tables do banco laboratorio.

Retome a agregação da Aula 09

O GROUP BY reúne os centros por cidade. Para cada grupo, COUNT(*) conta os centros e SUM soma suas capacidades. Revisar a Aula 09.

SQL · agrupar os centros por cidade
SELECT cidade,
       COUNT(*) AS total_centros,
       SUM(capacidade_diaria) AS capacidade_total
FROM centro_distribuicao
GROUP BY cidade
ORDER BY capacidade_total DESC;

Em um banco laboratorio recém-preparado, você também pode colar o script completo no editor e pressionar Alt + X para executá-lo. Faça a criação e a inserção uma vez. Nas próximas execuções, selecione apenas as consultas. Baixar o script de teste (.sql).

6. Pare, inicie e verifique a persistência

Rode os comandos do Compose na pasta do compose.yaml.

ComandoEfeito
docker compose stopPara o servidor e conserva o contêiner e o volume.
docker compose startInicia o contêiner já criado.
docker compose up -d --waitCria ou inicia o serviço e aguarda a verificação de saúde.
docker compose psMostra o estado do serviço e a porta publicada.
docker compose logs --tail=30 mysqlExibe as mensagens mais recentes do servidor.
docker compose downRemove o contêiner e a rede. O volume nomeado conserva os arquivos do banco.
Remoção do volume

O comando docker compose down -v também remove o volume mysql_dados e apaga os dados persistidos neste ambiente.

Para conferir a persistência, pare e inicie o contêiner. Depois que o serviço estiver saudável, reconecte no DBeaver e execute a consulta. O resultado esperado é 4.

SQL · contar os centros após reiniciar
SELECT COUNT(*) AS total
FROM centro_distribuicao;

7. Diagnostique problemas comuns

ProblemaO que conferir
Docker indisponívelAbra o Docker Desktop, aguarde o mecanismo iniciar e confira docker info.
Erro do WSL ou de virtualizaçãoVerifique wsl --version, as atualizações do WSL e a virtualização do computador.
Porta 3307 ocupadaEscolha outra porta livre no Windows, por exemplo 127.0.0.1:3308:3306. Rode docker compose up -d --wait e use 3308 no DBeaver.
Connection refusedConfira docker compose ps, os logs e a porta publicada.
Access deniedConfira a conta aluno e a senha registrada na primeira inicialização. Para alterar uma senha em um volume já inicializado, use uma sessão administrativa MySQL.
Tabela já existenteConsulte a tabela. Se estiver vazia, execute só a inserção. Se já tiver os quatro registros, execute apenas as consultas.
Confira antes de concluir

Prática da Aula 10 e referências

A prática de reservas usa um banco próprio, pratica_salas. Você pode executar no DBeaver os mesmos comandos SQL do roteiro e usar duas conexões separadas para o teste de concorrência.

Preparar o banco e o acesso de aluno

No PowerShell, entre no MySQL como administrador e informe a senha de MYSQL_ROOT_PASSWORD.

PowerShell · abrir a sessão administrativa
docker compose exec mysql mysql -u root -p
SQL · criar o banco da prática e conceder acesso
CREATE DATABASE IF NOT EXISTS pratica_salas CHARACTER SET utf8mb4;
GRANT ALL PRIVILEGES ON `pratica\_salas`.* TO 'aluno'@'%';

Depois, abra a conexão de aluno para pratica_salas. No arquivo .env da aplicação, use MYSQL_DATABASE=pratica_salas, MYSQL_USER=aluno, a senha dessa conta e MYSQL_PORT=3307 se você usou a porta deste guia.
